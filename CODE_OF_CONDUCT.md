# Code of Conduct

This project welcomes technical criticism, replication attempts, negative results, and alternative implementations.

Participants should:

- treat others with respect;
- critique claims and code rather than people;
- protect private/sensitive human data;
- disclose conflicts and limitations;
- avoid harassment, threats, doxxing, or discriminatory behavior;
- preserve null results and corrections rather than hiding them.

Repository maintainers may remove contributions or participation that violates these expectations.
