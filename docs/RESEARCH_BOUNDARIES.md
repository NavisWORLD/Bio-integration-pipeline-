# Research and Claim Boundaries

This project is intentionally buildable without turning implementation labels into scientific claims.

## Implemented here

- sensor adapter contract;
- quality scoring;
- adaptive baseline normalization;
- feature fusion;
- compact local CNS state;
- heartbeat/version records;
- append-only hash-chained event storage;
- optional Azure transport.

## Not established by this repository

- that any biometric value uniquely determines an emotion;
- medical diagnosis, prognosis, or treatment validity;
- that 12D/42D/54D software state describes physical spacetime dimensions;
- machine consciousness or subjective experience;
- universal predictive benefit from sensory conditioning;
- quantum advantage.

## Evidence discipline

When publishing results, report exact code revision, data source, sensor/device, sampling protocol, consent/retention policy, seeds where relevant, preprocessing, baseline, metrics, and null results.
